## How to use this list in your current project

1. Start by selecting 25-40 docs most relevant to your service offering (do not ingest all 100 at once).
2. Convert high-value pages into clean `.md` summaries.
3. Store the files in `backend/knowledge/`.
4. Run: `cd backend && npm run rag:sync`
5. Evaluate output quality; then incrementally add more docs.

## Important

- Prefer official docs and your own internal delivery docs.
- Do not ingest copyrighted content you do not have permission to use.
- Keep each ingested file focused (small topic slices) for better retrieval quality.
